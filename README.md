## 📖 Описание репозитория

Этот репозиторий содержит **задания**, направленные на отработку концепций Python:

* встроенные типы данных
* аннотации типов (type hints)
* функции без `return` (через `print`)
* работа со списками, множествами и словарями
* базовая логика (условия, циклы, `match/case`)
* соблюдение стиля кода и требований линтеров

Все задачи оформлены как **отдельные Python-файлы**, каждый файл можно запускать напрямую.

## ✅ Задание 1. Встроенные типы данных (`data_types/task_1.py`)

Цель: познакомиться со **всеми базовыми mutable и immutable типами Python**, корректно указать сигнатуры и проверить типы через `isinstance`.

### 🔒 Immutable (неизменяемые типы)

| Тип         | Описание                                 |
| ----------- | ---------------------------------------- |
| `int`       | Целые числа                              |
| `str`       | Строки (Unicode)                         |
| `float`     | Числа с плавающей точкой                 |
| `bool`      | Логические значения                      |
| `tuple`     | Неизменяемая упорядоченная коллекция     |
| `frozenset` | Неизменяемое множество                   |
| `bytes`     | Последовательность байтов                |
| `range`     | Неизменяемая числовая последовательность |

### 🔧 Mutable (изменяемые типы)

| Тип         | Описание                             |
| ----------- | ------------------------------------ |
| `list`      | Изменяемый список                    |
| `dict`      | Изменяемый словарь                   |
| `set`       | Изменяемое множество                 |
| `bytearray` | Изменяемая последовательность байтов |

Формат задания:

* обязательные сигнатуры типов
* `print(type(x))`
* `assert isinstance(x, type)`

## ✅ Задание 2. Минимум из двух чисел (`simple_def/task_1_min_int.py`)

Реализовать функцию:

* принимает **два целых числа**
* **печатает** минимальное из них
* без использования `return`

Особенности:

* snake_case
* простые докстринги
* наглядный вызов функции в конце файла

---

## ✅ Задание 3. Уникальный min и max (`simple_def/task_2_unique_min_max.py`)

Реализовать функцию, которая:

* принимает `list[int]`
* находит **уникальные** значения
* печатает минимальное и максимальное число

Реализовано в двух вариантах:

1. Через **множество (set / генератор множества)**
2. Через **циклы без использования set**

Требования:

* сигнатуры типов
* отсутствие `return`
* простые докстринги
* корректная обработка пустого списка

## ✅ Задание 4. Месяц и сезон (`simple_def/task_3_month_season.py`)

Функция:

* принимает номер месяца (`int`)
* определяет сезон через `match/case`
* печатает сезон и название месяца

Используется:

* словарь месяцев
* `match / case`
* ввод через `input()`

## 🧹 Линтеры и стиль кода

Проект использует **pylint**.

### Установка окружения

```bash
pip install pipenv
pipenv install --dev
```

### Проверка линтером

Проверить всю папку:

```bash
pylint data_types simple_def
```

Проверить конкретный файл:

```bash
pylint simple_def/task_2_unique_min_max.py
```

Требования:

* snake_case
* аннотации типов
* понятные докстринги
* отсутствие "магии" и лишних конструкций
