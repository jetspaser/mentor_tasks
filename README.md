## 📖 Описание проекта

Этот учебный проект демонстрирует работу с **встроенными типами данных Python**, их инициализацию, присвоение значений с использованием **сигнатур (type hints)**, а также проверку соответствия типов. Особое внимание уделено различию между **изменяемыми (mutable)** и **неизменяемыми (immutable)** типами данных.

Проект создан в рамках обучения автоматизированному тестированию для глубокого понимания фундаментальных основ языка Python.

## 🎯 Цели проекта

- ✅ **Изучить** все встроенные типы данных Python
- ✅ **Понять разницу** между изменяемыми и неизменяемыми типами
- ✅ **Научиться** правильно использовать type hints (сигнатуры)
- ✅ **Освоить** практическое применение каждого типа в автотестах
- ✅ **Выполнить** практическое задание по каждому типу данных

## 📊 Классификация типов данных

### 🔒 **Неизменяемые типы (Immutable)**
Типы данных, которые **нельзя изменить** после создания:

| Тип | Описание | Пример |
|-----|----------|--------|
| **`int`** | Целые числа | `42`, `-10`, `0` |
| **`float`** | Числа с плавающей точкой | `3.14`, `-0.5`, `2.0` |
| **`bool`** | Логические значения | `True`, `False` |
| **`str`** | Строки (текст) | `"Hello"`, `'Python'` |
| **`tuple`** | Кортежи | `(1, 2, 3)`, `("a", "b")` |
| **`frozenset`** | Замороженные множества | `frozenset([1, 2, 3])` |
| **`bytes`** | Байтовые строки | `b"hello"`, `b"\x00\x01"` |

### 🔧 **Изменяемые типы (Mutable)**
Типы данных, которые **можно изменять** после создания:

| Тип | Описание | Пример |
|-----|----------|--------|
| **`list`** | Списки | `[1, 2, 3]`, `["a", "b", "c"]` |
| **`dict`** | Словари | `{"name": "John", "age": 30}` |
| **`set`** | Множества | `{1, 2, 3}`, `{"a", "b", "c"}` |
| **`bytearray`** | Изменяемые байты | `bytearray(b"hello")` |
