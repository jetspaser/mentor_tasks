🎯 Введение
Этот проект демонстрирует работу с встроенными типами данных Python, их инициализацию, присвоение значений с использованием сигнатур (type hints), а также проверку соответствия типов. Особое внимание уделено различию между изменяемыми (mutable) и неизменяемыми (immutable) типами данных.



📊 Изменяемые vs неизменяемые типы



🛡️ Неизменяемые типы (Immutable)
int - целые числа

float - числа с плавающей точкой

complex - комплексные числа

str - строки

bool - логические значения

tuple - кортежи

frozenset - замороженные множества

bytes - байтовые строки

None - специальный тип для отсутствия значения



🔧 Изменяемые типы (Mutable)

list - списки

dict - словари

set - множества

bytearray - изменяемые байтовые строки




🚀 Практическое задание


Для каждого встроенного типа данных выполнить:

Инициализацию и присвоение значения переменной с указанием сигнатуры (type hint)

Печать в консоль типа данных переменной

Проверку на соответствие типа переменной указанной сигнатуре
